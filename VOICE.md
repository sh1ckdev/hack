# Локальный голосовой помощник

Голосовые команды распознаёт локальный сервер [whisper.cpp](https://github.com/ggml-org/whisper.cpp). Аудио и распознанный текст обрабатываются на компьютере, где запущен дашборд. Для первой установки нужны Git, CMake и инструменты командной строки Xcode на macOS.

```sh
npm run voice:setup
npm run dev:voice
```

`voice:setup` собирает сервер Whisper и скачивает мультиязычную модель `base` (около 142 МБ). `dev:voice` запускает Whisper на `127.0.0.1:8178` вместе с Vite; остановка Vite завершает и сервер Whisper. Для обычного запуска без микрофона остаётся команда `npm run dev`.

Нажмите «Голос», разрешите доступ к микрофону, произнесите команду и нажмите кнопку ещё раз. Запись автоматически ограничена 15 секундами. Команды фильтруют текущий список: «покажи критические», «покажи просроченные», «назначенные координаторам», «сбрось фильтры»; номер INC или другое описание используется как текст поиска. Голосовые команды не меняют заявки.

Кнопка работает в браузере, где доступен `getUserMedia` (обычно `localhost` или HTTPS). Распознавание выполняется моделью на компьютере после разовой загрузки модели.

## Разбор команд с ИИ

`npm run dev:voice` также запускает локальный llama.cpp, если доступны сервер и модель. Можно запустить его отдельно командой `npm run voice:ai`. Подойдёт уже скачанная в Ollama модель `qwen2.5:1.5b` или совместимая GGUF модель по пути `.local/models/voice.gguf`. Путь можно переопределить через `VOICE_AI_MODEL_PATH`.

По умолчанию скрипт ищет `llama-server` в `.local/llama.cpp/build/bin/`. Собрать его можно по [инструкции llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md) или указать готовый исполняемый файл через `VOICE_LLAMA_SERVER`. Сервер слушает только `127.0.0.1:8180`.

Попробуйте «Что у координаторов уже просрочено?». ИИ включает оба фильтра одновременно. При недоступности модели остаются простые команды и поиск по номеру INC.

Спросите «Что взять первым и почему?», чтобы увидеть рекомендацию по текущей очереди, срок и следующий шаг. Затем спросите «Кто её ведёт?» или «Что по ней менялось?». Помощник использует тот же номер заявки. Эти три формулировки работают и при недоступности Qwen, а свободные формулировки разбирает модель.

В том же окне можно выбрать «Ввести текст» или «Записать вопрос». Исправьте расшифровку, если нужно, и нажмите «Спросить». Диалог использует текущий снимок и две последние пары реплик. Номера заявок в ответах открывают соответствующую карточку. Кнопка «Озвучить» использует установленный локальный русский голос устройства.
